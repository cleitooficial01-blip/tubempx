# Tube MPX - Baixador de Vídeos do YouTube

Site para baixar vídeos do YouTube em MP4 e MP3, sem marca d'água e de graça.

## 🚀 Como usar

### 1. Instalar dependências

```bash
pip install -r requirements.txt
```

### 2. Rodar o servidor

```bash
python app.py
```

### 3. Abrir no navegador

Abra: http://localhost:5000

## 📋 Funcionalidades

- ✅ Baixar vídeos do YouTube em várias qualidades (360p, 480p, 720p, 1080p, 4K)
- ✅ Converter para MP3 (apenas áudio)
- ✅ Interface moderna e responsiva
- ✅ Sem marca d'água
- ✅ Download direto no navegador
- ✅ Múltiplos formatos disponíveis

## 🛠️ Tecnologias

- **Backend**: Python + Flask
- **Download**: yt-dlp
- **Frontend**: HTML + CSS + JavaScript
